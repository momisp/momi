# 倒数计时器（静态页面）

纯前端倒数计时器：可设标题与分钟数，支持开始、暂停、继续、重置；自然结束或「关闭本次计时并记录」会写入历史（浏览器 `localStorage`，最多保留 50 条）。

## 本地打开

将本文件夹解压/克隆后，用浏览器直接打开根目录下的 `index.html` 即可。`styles.css` 与 `app.js` 与 `index.html` 同级，使用相对路径加载。

> 说明：通过 `file://` 打开时，`localStorage` 一般仍可用；若遇到浏览器安全策略限制，请改用下方本地服务器方式。

## 使用本地静态服务器（推荐）

在项目根目录（含 `index.html` 的目录）执行：

```bash
npx --yes serve .
```

终端会打印本地访问地址（通常为 `http://localhost:3000`），在浏览器中打开即可。

也可用其他任意静态服务器，只要根目录指向本文件夹即可。
