# 墨秘（momi）— 辅助写小说产品需求文档

> 版本：v0.1 | 状态：草案 | 说明：用户附图识图失败，界面与功能条目依据「辅助写小说」典型单页原型及项目名 momi 整理，第 8 章标注待与用户原图核对项。

## 1. 背景与目标

### 1.1 背景

网文与长篇虚构创作普遍存在卡文、设定遗忘、前后矛盾、章节管理分散等问题。创作者常在 Word、备忘录与多个 AI 工具之间切换，上下文难以延续，影响连载效率与作品质量。

### 1.2 产品定位

**墨秘（momi）** 是一款面向个人作者的 **AI 辅助长篇小说创作工作台**，以「作品 → 章节 → 正文」为主线，将大纲、角色、世界观与 AI 续写/润色/扩写集中在一页完成，降低工具切换成本。

### 1.3 目标（可衡量）

| 目标 | 说明 | 指标（首期） |
|------|------|----------------|
| G1 提升写作效率 | 卡文时可基于前文与设定一键续写 | 单章从打开到产出 500 字中位时长较纯编辑器缩短 30%（内测问卷） |
| G2 保障设定一致 | 写作时自动挂载当前作品设定摘要 | 续写请求 100% 携带作品级上下文（角色+世界观+本章前情） |
| G3 结构化管理 | 章节树、大纲、灵感可检索 | 单作品支持 ≥50 章、≥20 角色档案 |
| G4 可交付原型 | 单页 HTML 可演示核心流程 | 无后端条件下完成「选章→编辑→模拟 AI→导出文本」闭环 |

### 1.4 非目标（首期不做）

- 多人协同编辑、版权交易、社区分发
- 全自动「一键成书」无人值守流水线
- 移动端原生 App（首期仅 Web 响应式）

## 2. 用户与场景

### 2.1 目标用户

| 用户类型 | 特征 | 核心诉求 |
|----------|------|----------|
| U1 连载网文作者 | 日更/周更，熟悉爽点节奏 | 快速续写、不崩人设、章节进度可视 |
| U2 业余长篇爱好者 | 兼职写作，素材碎片化 | 设定归档、灵感收集、低学习成本 |
| U3 创意写作练习者 | 以完成为主，重结构 | 大纲引导、AI 润色学习表达 |

### 2.2 核心场景

**S1 开书立项**  
用户新建作品，填写书名、类型、简介，可选从「一句话梗概」生成初始大纲与主角卡片。

**S2 搭骨架**  
在「大纲」面板维护全书/分卷/章节梗概；在「角色」「世界观」面板补充设定，供后续 AI 引用。

**S3 沉浸式写章**  
左侧选择章节，中间编辑正文；右栏 AI 助手根据指令续写、润色或扩写选中段落，结果可插入或替换。

**S4 卡文救场**  
输入一句剧情走向或选择「续写」，系统结合前文摘要与设定生成 1～3 个方向供挑选插入。

**S5 复盘导出**  
按章节或全书导出纯文本/Markdown，本地备份。

## 3. 功能范围（核心流程）

### 3.1 信息架构（单页三区）

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：Logo 墨秘 | 作品切换 ▼ | 保存状态 | 导出 | 设置          │
├──────────┬──────────────────────────────┬───────────────────┤
│ 左栏     │ 中栏 · 写作区                 │ 右栏 · 辅助区      │
│ 章节树   │ 章节标题 | 正文编辑器 | 字数   │ Tab：AI|角色|世界| │
│ +新建章  │ 工具条：加粗/预览/专注模式     │ 大纲|灵感          │
└──────────┴──────────────────────────────┴───────────────────┘
```

### 3.2 功能清单

| 模块 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| 作品 | 新建/切换/重命名作品 | P0 | 顶栏下拉；本地存储多作品 |
| 章节 | 章节树、排序、新建、删除（二次确认） | P0 | 左栏；显示完成态图标 |
| 写作 | 富文本或纯文本编辑、自动保存、字数统计 | P0 | 中栏；失焦/定时保存 |
| AI 助手 | 续写、润色、扩写、自由对话 | P0 | 右栏默认 Tab；首期可 Mock |
| AI 助手 | 携带上下文（作品设定+本章前文） | P1 | 请求前组装 prompt 预览（可选） |
| 角色 | 角色卡片：姓名、身份、性格、关系 | P0 | 右栏 Tab；列表+详情表单 |
| 世界观 | 时代、地理、规则、势力等条目 | P1 | 结构化键值或 Markdown |
| 大纲 | 三级：全书摘要 / 卷 / 章梗概 | P0 | 与章节树联动高亮 |
| 灵感 | 便签列表、标签、置顶 | P2 | 快速记入，写作时可插入引用 |
| 导出 | 当前章/全书导出 .txt 或 .md | P1 | 顶栏按钮 |
| 设置 | 字体、主题、AI 接口配置（Key/模型） | P2 | 本地加密存储 Key |

### 3.3 核心流程（主路径）

```mermaid
flowchart LR
  A[新建作品] --> B[填写设定与大纲]
  B --> C[新建章节]
  C --> D[编辑正文]
  D --> E{需要 AI?}
  E -->|是| F[选择续写/润色/扩写]
  F --> G[预览并插入正文]
  E -->|否| H[自动保存]
  G --> H
  H --> I[导出/下一章]
```

### 3.4 功能交互细则（摘要）

1. **章节切换**：切换前若有未保存修改，提示「保存 / 不保存 / 取消」。
2. **AI 续写**：默认取编辑器光标前 N 字（可配置，默认 2000）+ 作品设定摘要；生成结果显示在右栏对比区，用户点击「插入光标处」或「替换全文」。
3. **AI 润色/扩写**：必须先选中正文片段；无选中时按钮禁用并提示。
4. **角色/世界观**：变更后标记「设定已更新」，下次 AI 请求使用新版本。
5. **大纲与章节**：章节节点可绑定「本章梗概」字段，打开章节时在标题下展示一行提示。

## 4. 非功能要求

| 类别 | 要求 |
|------|------|
| 性能 | 单作品 100 章、单章 2 万字时，切换章节 UI 响应 &lt; 300ms（本地 IndexedDB） |
| 可用性 | 主路径 3 次点击内可从章节树进入 AI 续写；关键按钮具备中文 tooltip |
| 兼容 | Chrome/Edge/Safari 最近两个大版本；最小宽度 1024px 完整三栏，&lt;768px 折叠左栏为抽屉 |
| 安全 | API Key 仅存本地，不上传业务服务器（若仅静态页）；HTTPS 部署 |
| 可访问 | 表单控件具备 label；对比度满足 WCAG AA（深色主题可选） |
| 可维护 | 首期单页 HTML + 模块化 JS；后续可拆分为 SPA 而不改信息架构 |

## 5. 界面与信息结构要点

### 5.1 顶栏

- 左：品牌「墨秘 momi」
- 中：当前作品名下拉（含「+ 新建作品」）
- 右：保存状态（已保存 / 保存中… / 保存失败）、「导出」、「设置」图标按钮

### 5.2 左栏 · 章节

- 标题「章节」+「+ 新建」
- 树形列表：卷（可选）> 章；状态图标：空白 / 进行中 / 已完成
- 底部：全书进度条（已完成章数/总章数）

### 5.3 中栏 · 写作区

- 章节标题（可编辑 input）
- 本章梗概（只读一行，来自大纲）
- 正文 `contenteditable` 或 textarea
- 底栏：本章字数 | 今日字数 | 专注模式开关

### 5.4 右栏 · Tab

| Tab 名称 | 内容要点 |
|----------|----------|
| AI 助手 | 快捷按钮：续写、润色、扩写；多行输入；生成结果区；插入/替换 |
| 角色 | 左侧名单，右侧表单：姓名、标签、人设、关系 |
| 世界观 | 分类折叠：时代、地理、势力、规则 |
| 大纲 | 全书摘要编辑；章节梗概与树联动 |
| 灵感 | 卡片列表，支持搜索标签 |

### 5.5 视觉风格（建议）

- 深色写作为主（减眼疲劳），强调色用于 AI 相关按钮（如琥珀/青绿）
- 字体：正文宋体或思源宋体，UI 无衬线
- 与附图核对项：主色、圆角、图标风格需用户对齐原稿

## 6. 边界与异常（空态、错误、权限）

### 6.1 空态

| 场景 | 展示 |
|------|------|
| 无作品 | 中栏引导「创建第一部作品」+ 示例模板 |
| 无章节 | 左栏说明 +「创建第一章」主按钮 |
| 正文为空 | 字数 0；AI 续写提示「将从头生成开篇」 |
| 无角色/世界观 | 对应 Tab 空状态插画 +「添加第一条设定」 |
| AI 无 Key | 设置引导配置；Mock 模式可体验流程 |

### 6.2 错误与重试

| 错误 | 处理 |
|------|------|
| 自动保存失败 | 顶栏红色提示 +「重试」；本地草稿保留 |
| AI 请求超时/失败 | 右栏 Toast + 保留用户输入；可重试 |
| 导出失败 | 提示浏览器权限或磁盘空间 |
| 章节删除 | 二次确认；可软删除 7 天内恢复（P2） |

### 6.3 权限（首期）

- 单机单用户，无账号体系；数据存 `localStorage` / `IndexedDB`
- 后期若加云同步：作品级读写权限、API Key 仅本人可见

### 6.4 边界条件

- 单章超过 5 万字：警告性能，建议拆章
- 同时打开多个浏览器 Tab：以最后写入为准，冲突时提示（P2 做版本合并）

## 8. 待定项与风险

### 8.1 待与用户原图核对（附图识图失败）

- [ ] 顶栏 exact 文案与按钮数量是否与图一致  
- [ ] 右栏 Tab 名称、顺序、是否含「伏笔」「记忆」等扩展 Tab  
- [ ] 是否存在「拆书」「批量生成」「时间线」等图中字样功能  
- [ ] 配色、Logo、产品中文名是否确认为「墨秘」  
- [ ] AI 为真实 API 还是仅前端 Mock 的期望  

### 8.2 产品待定

| 项 | 选项 | 建议 |
|----|------|------|
| 编辑器 | 纯文本 vs Markdown vs 富文本 | 首期 Markdown/纯文本 |
| AI 供应商 | OpenAI 兼容 / 国产大模型 | 抽象统一接口 |
| 数据同步 | 仅本地 vs 云备份 | 先本地，预留导出 |
| 大纲层级 | 2 级 vs 3 级 | 3 级（书/卷/章） |

### 8.3 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 原图需求与推断不一致 | 返工 UI | 用户确认 8.1 清单后迭代 v0.2 |
| AI 成本与质量波动 | 体验不稳定 | Mock + 可配置模型；限制单次生成长度 |
| 本地存储丢失 | 用户资产损失 | 强提示定期导出；后期云备份 |
| 长篇一致性 | 剧情吃书 | 设定摘要强制注入；章节前情摘要（P1） |
