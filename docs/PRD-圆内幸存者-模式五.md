# 模式五 · 圆内幸存者（修仙试炼）

## 核心循环

1. 玩家在 **灵气结界**（圆）内 WASD 移动  
2. 功法 **自动** 攻击近处妖兽  
3. 拾取 **灵韵**（经验）破境，三选一神通  
4. 撑满 **3 分钟** 渡劫成功；气血归零则道消  

## 修仙呈现

- 主角：道袍 + 灵盾光环；敌：浊气小妖 / 狼妖 / 影魔 / 渡劫兽  
- 特效：剑气、雷环、符箓、破境灵波  
- 音频：斩妖、雷法、破境、败北/胜利；BGM 可选五音 ambient  

## 入口

- 本地：`npm run dev` → `/play/circle-survivor`  
- 挂载组件：`CircleSurvivorHost.jsx`  

## 数值要点（见 `balance.js`）

- `spawnBudgetAt(t)`：t&lt;30 温和，90s 后显著加压  
- 首次升级约 20–40s（取决于走位聚怪）  
- 150s 起周期性 **渡劫兽**
