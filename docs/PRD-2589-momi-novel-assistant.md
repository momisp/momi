## 1. 背景与目标

### 1.1 背景

网文与自出版创作门槛持续降低，但长篇创作仍面临三类痛点：

- **结构失控**：缺少清晰大纲与章节规划，写到中后期容易崩线、弃坑。
- **设定遗忘**：人物关系、世界观规则分散在笔记与聊天记录中，难以保持一致性。
- **写作效率低**：从空白页到成稿耗时长，润色、续写、扩写重复劳动多。

现有通用 AI 对话工具虽能生成片段，但缺乏「作品—设定—大纲—章节」的结构化工作流，产出难以沉淀为可编辑、可回溯的创作资产。

### 1.2 产品定位

Momi 是一款 **AI 辅助长篇小说创作** 的 Web 应用，将创作过程拆解为可管理的结构化模块，通过向导式流程与章节级 AI 能力，帮助作者从灵感到成稿高效推进。

### 1.3 目标（可量化）

| 目标维度 | 指标 | 首版目标 |
| --- | --- | --- |
| 创作启动 | 新建作品到生成首版大纲+角色+世界观 | ≤ 10 分钟 |
| 章节产出 | 单章 AI 辅助生成（含用户微调） | ≤ 5 分钟/章（2000 字量级） |
| 数据安全 | 用户作品本地/服务端持久化，刷新不丢失 | 100% |
| 可用性 | 核心流程（新建→编辑→保存）无阻断完成 | 首版必达 |

### 1.4 非目标（首版不做）

- 多人协同实时编辑
- 社区连载发布与读者互动
- 版权交易、付费订阅体系
- 移动端原生 App（首版以 Web 响应式为主）

## 2. 用户与场景

### 2.1 目标用户

| 用户类型 | 特征 | 核心诉求 |
| --- | --- | --- |
| 业余创作者 | 有故事想法，写作经验有限 | 快速搭骨架、降低开坑难度 |
| 网文作者 | 有连载习惯，追求更新效率 | 批量生成章节、润色续写 |
| 设定党 | 重视世界观与人物一致性 | 结构化设定管理、减少前后矛盾 |

### 2.2 核心场景

**场景 A：从零开坑**

> 用户点击「新建作品」，填写书名、类型、简介 → 使用智能向导 → AI 生成世界观、角色、大纲 → 进入项目工作台继续完善。

**场景 B：按章写作**

> 用户在章节列表选中某一章 → 在编辑器中查看/编辑正文 → 使用「续写 / 润色 / 重写 / 扩写」→ 保存并进入下一章。

**场景 C：设定维护**

> 写作过程中发现角色性格需调整 → 打开「角色设定」修改 → 后续 AI 生成自动引用最新设定。

**场景 D：灵感补充**

> 卡文时打开「灵感」面板 → 输入关键词或当前困境 → AI 给出情节走向、冲突点、桥段建议 → 用户选用并写入大纲或章节。

## 3. 功能范围（核心流程）

### 3.1 信息架构总览

```
首页（作品库）
├── 新建作品 / 智能向导
├── 作品详情（项目工作台）
│   ├── 概览
│   ├── 大纲
│   ├── 角色设定
│   ├── 世界观
│   ├── 章节（列表 + 编辑器）
│   └── 灵感
└── 设置（账户 / AI 模型 / 写作偏好）
```

### 3.2 模块功能清单

#### 3.2.1 首页 · 我的作品

| 功能 | 描述 | 优先级 |
| --- | --- | --- |
| 作品列表 | 卡片展示：封面（可选）、书名、类型、更新时间、字数统计 | P0 |
| 新建作品 | 入口按钮，跳转创建向导 | P0 |
| 搜索 / 筛选 | 按书名、类型筛选 | P1 |
| 删除作品 | 二次确认后删除及关联数据 | P0 |

#### 3.2.2 智能向导（新建作品）

分步表单，支持「上一步 / 下一步 / 跳过」：

| 步骤 | 字段 / 动作 | 说明 |
| --- | --- | --- |
| ① 基本信息 | 书名*、类型*（玄幻/都市/言情/科幻/悬疑/其他）、简介、目标字数、写作风格（可选） | 类型影响 AI 提示词模板 |
| ② 核心设定 | 时代背景、核心冲突、主角简述 | 可手动填写或「AI 帮我想」 |
| ③ AI 生成 | 一键生成：世界观摘要、主要角色（3–5 人）、分卷/分章大纲 | 展示生成进度与结果预览 |
| ④ 确认创建 | 用户可编辑生成结果后确认，创建项目并进入工作台 | — |

#### 3.2.3 项目工作台 · 概览

- 作品元信息：书名、类型、简介、创建/更新时间
- 进度概览：总字数、已完成章节数 / 总章节数
- 快捷入口：继续写作（跳转最近编辑章节）、编辑大纲、管理角色

#### 3.2.4 大纲管理

| 功能 | 描述 | 优先级 |
| --- | --- | --- |
| 树形结构 | 支持「卷 → 章」两级（首版可扁平仅章） | P0 |
| 增删改排序 | 章节标题、摘要、预计字数 | P0 |
| AI 重新生成 | 基于当前设定重新生成全部或选中节点大纲 | P1 |
| 跳转写作 | 点击章节节点进入对应章节编辑器 | P0 |

#### 3.2.5 角色设定

| 功能 | 描述 | 优先级 |
| --- | --- | --- |
| 角色卡片 | 姓名、性别、年龄、身份、性格、外貌、目标、秘密/伏笔 | P0 |
| 人物关系 | 文本描述或简单关系标签（师徒/恋人/敌对等） | P1 |
| 增删改 | CRUD + 列表/卡片视图切换 | P0 |
| AI 补全 | 根据已有信息补全角色细节 | P1 |

#### 3.2.6 世界观设定

| 区块 | 内容 |
| --- | --- |
| 时代与地理 | 时间线、主要地点 |
| 势力 / 组织 | 名称、立场、简介 |
| 规则体系 | 修炼/科技/社会规则等（按类型展示不同模板） |
| 自由备注 | 富文本或 Markdown 补充说明 |

支持手动编辑；向导阶段 AI 预填，用户可覆盖。

#### 3.2.7 章节写作（核心）

**布局（三栏，参考图推断）：**

- **左栏**：章节列表（序号、标题、字数、状态：未写/草稿/已定稿）
- **中栏**：正文编辑器（Markdown 或富文本，支持实时字数统计）
- **右栏**：AI 助手面板

**AI 助手能力：**

| 操作 | 输入 | 输出行为 |
| --- | --- | --- |
| 续写 | 可选续写方向提示 | 在当前光标后追加内容 |
| 润色 | 选中段落或全文 | 优化文笔，保持原意 |
| 重写 | 选中段落 + 改写要求 | 替换选中内容 |
| 扩写 | 选中段落 + 目标字数 | 扩展细节与描写 |
| 生成本章 | 读取本章大纲摘要 | 根据大纲生成初稿 |

**编辑能力：**

- 自动保存（防抖，如 3 秒无操作保存）
- 手动保存
- 撤销 / 重做（编辑器原生能力）
- 章节状态标记：草稿 / 定稿

#### 3.2.8 灵感

| 功能 | 描述 | 优先级 |
| --- | --- | --- |
| 灵感生成 | 输入主题/困境，AI 返回 3–5 条情节建议 | P1 |
| 收藏灵感 | 保存至作品灵感库，可关联到大纲节点 | P2 |
| 一键引用 | 将选中灵感插入大纲摘要或章节备注 | P2 |

#### 3.2.9 设置

| 项 | 说明 |
| --- | --- |
| AI 模型配置 | API Key、模型选择（OpenAI / Claude / Gemini 等，至少支持一种） |
| 写作偏好 | 默认单章目标字数、语言风格（简洁/华丽/口语等） |
| 账户 | 登录/登出（首版可本地单用户，预留多用户扩展） |
| 数据导出 | 导出为 Markdown 或 TXT（P1） |

### 3.3 核心用户流程（主路径）

```mermaid
flowchart LR
    A[打开首页] --> B[新建作品]
    B --> C[智能向导填写]
    C --> D[AI 生成设定与大纲]
    D --> E[进入项目工作台]
    E --> F[选择章节]
    F --> G[编辑 / AI 辅助写作]
    G --> H[保存]
    H --> F
    H --> I[完成或导出]
```

## 4. 非功能要求

### 4.1 性能

| 项 | 要求 |
| --- | --- |
| 首屏加载 | 作品库页 ≤ 3s（常规模拟网络） |
| 编辑器交互 | 输入无明显卡顿（万级字符内） |
| AI 请求 | 流式输出首 token ≤ 5s（依赖第三方 API）；超时 60s 提示重试 |
| 自动保存 | 保存请求 ≤ 1s 返回（本地网络） |

### 4.2 可用性与兼容

- 支持 Chrome、Edge、Safari 最近两个大版本
- 最小宽度 1280px 完整三栏布局；≤ 1024px 右栏 AI 面板可折叠为抽屉
- 界面语言：简体中文

### 4.3 安全与隐私

- API Key 仅存服务端或加密存储，不在前端明文展示
- 用户作品数据按账户隔离（多用户场景）
- 删除作品需二次确认，逻辑删除或物理删除策略需在技术方案中明确

### 4.4 可靠性

- 自动保存失败时明确提示，不静默丢失
- AI 生成中断可取消；已生成部分可保留
- 关键写操作支持幂等，避免重复提交产生重复章节

### 4.5 可维护性

- 前后端分离，RESTful 或 GraphQL API
- AI 提示词模板可配置，便于后续迭代而不改业务代码

## 6. 边界与异常（空态、错误、权限）

### 6.1 空态

| 场景 | 展示 |
| --- | --- |
| 无作品 | 插画 + 引导文案 +「新建作品」按钮 |
| 无章节 | 「暂无章节，可从大纲生成或手动新建」 |
| 无角色 / 世界观 | 提示「完成向导后将自动填充，也可手动添加」 |
| AI 无结果 | 「暂未生成内容，请调整提示后重试」 |

### 6.2 错误处理

| 错误类型 | 用户提示 | 系统行为 |
| --- | --- | --- |
| 网络断开 | 「网络异常，请检查连接」 | 自动保存队列重试 3 次 |
| AI API 失败 | 「AI 服务暂时不可用，请稍后重试」 | 记录错误日志，不覆盖已有正文 |
| AI 超时 | 「生成超时，可重试或缩短内容范围」 | 终止流式输出 |
| 保存失败 | 「保存失败，请勿关闭页面」+ 重试按钮 | 本地缓存草稿（localStorage 兜底，可选） |
| 表单校验 | 字段级红字提示（如书名为空） | 阻止提交 |

### 6.3 权限

| 角色 | 权限 |
| --- | --- |
| 未登录（若启用登录） | 仅可浏览登录页；或首版允许本地访客模式（待确认） |
| 普通用户 | 仅 CRUD 本人作品与设定 |
| 管理员（后续） | 用户管理、系统配置 |

### 6.4 边界条件

- 书名长度：1–50 字；简介 ≤ 500 字
- 单章正文建议上限：50,000 字（超出警告，不硬拦）
- 并发生成：同一章节同时仅允许一个 AI 任务
- 删除作品：不可恢复（或 30 天回收站，首版建议简单不可恢复 + 强确认）
