# 写作工作台 · 产品需求文档（PRD）

## 1. 背景与目标

### 背景
写作者在构思与成稿阶段需要在同一界面中切换「结构（大纲/提纲）」「辅助素材（脑图/关键词/剪贴板）」与「正文创作」，避免多工具切换带来的上下文丢失。本产品以单页静态应用形式交付，降低部署与使用门槛。

### 目标
- 交付一个**单文件** `写作工作台.html`：HTML、CSS、原生 JavaScript 全部内联，浏览器双击即可运行。
- **零构建、零外部依赖**：打开时不产生外部网络请求，控制台无报错。
- 界面语言为**简体中文**，布局**响应式**，覆盖桌面宽屏与窄屏（≤900px）堆叠场景。
- 实现规格中定义的**六大功能区**与**六项核心交互**，满足文末验收条目。

### 成功指标
- 用户可在 3 秒内理解界面分区（大纲 / 三栏工具 / 提纲+写作区）。
- 六项交互在主流桌面浏览器中可重复操作且状态一致（选中态、字数、弹窗回写）。

## 2. 用户与场景

### 目标用户
- 需要写长文、报告、方案的用户（学生、内容运营、产品/市场文案等）。
- 习惯在本地或离线环境写作、不愿安装 IDE 或 SaaS 的用户。

### 典型场景
| 场景 | 用户行为 | 产品支撑 |
|------|----------|----------|
| 搭结构 | 浏览左侧章节树，点选当前章 | 大纲单选高亮，写作区工具条展示当前章节 |
| 列要点 | 在工作区左列点选提纲条目 | 提纲单选高亮，引导写作焦点 |
| 扩思路 | 查看/编辑顶部脑图缩略图 | 缩略图点击打开弹窗，保存后回写预览 |
| 标主题 | 维护关键词标签 | 输入+添加/Enter 追加胶囊标签 |
| 贴素材 | 从剪贴板条目插入引用或数据 | 点击条目追加至写作区末尾并刷新字数 |
| 成正文 | 在写作区输入长文 | 实时去空白字数统计 |

## 3. 功能范围（核心流程）

### 3.1 信息架构（从左到右、从上到下）

```
┌──────────┬─────────────────────────────────────────────┐
│  大纲    │  顶部三栏（Grid 1fr 1fr 1fr）                 │
│ 220px    │  [脑图缩略] [关键词] [剪贴板]                 │
│ 全高     ├─────────────────────────────────────────────┤
│          │  工作区（横向 Flex）                          │
│          │  [提纲 200px] [写作区 flex:1]                 │
└──────────┴─────────────────────────────────────────────┘
```

根容器 `.app`：`display:flex; height:100vh; overflow:hidden`。右侧 `.main` 纵向 `flex:1`，`gap:12px`；上方工具区 `min-height:140px`，下方工作区 `flex:1`。

### 3.2 模块功能清单

| 模块 | 功能要点 | 交互 |
|------|----------|------|
| 大纲 | 两级章节树（章/节），示例三章三节 | 点击单项：清除其它 `active`，当前项 `active`（单选），`data-id` |
| 脑图卡片 | 虚线缩略容器 + 示意 SVG | 点击开弹窗；hover 主题蓝/浅蓝；保存回写缩略区 |
| 关键词 | 胶囊标签 + 输入 +「添加」 | trim 非空后追加标签；Enter 同添加 |
| 剪贴板 | 列表项含正文、相对时间、`data-text` | 点击插入写作区末尾，补 `\n\n` 规则，聚焦并重算字数 |
| 提纲 | 序号徽标 + 要点列表，`data-section` | 单选 `active` |
| 写作区 | `textarea` + 工具条（章节、字数） | `input` 去空白计字数；placeholder 含操作提示 |
| 脑图弹窗 | 放大编辑区 + 取消/保存 | ×、取消、遮罩关闭；保存写回并关闭 |

### 3.3 核心用户流程

1. **进入页面** → 加载示意 SVG 至缩略预览与弹窗编辑区 → 默认大纲/提纲示例态可选。
2. **选定章节** → 大纲项高亮 →（建议）工具条「当前章节」文案与所选章一致。
3. **选定提纲要点** → 提纲项高亮 → 用户转向写作区创作。
4. **维护脑图** → 点击缩略 → 弹窗编辑 →「保存并缩小」→ 缩略区更新。
5. **插入剪贴板** → 点击条目 → 写作区末尾追加 → 字数更新、写作区聚焦。
6. **持续写作** → 输入触发字数统计（去除全部空白字符后的长度）。

### 3.4 技术交付约束
- 单文件命名：`写作工作台.html`。
- JS 使用 IIFE 包裹，依赖元素 ID 见规格第 6 节，**不得更名或删除**。

## 4. 非功能要求

| 类别 | 要求 |
|------|------|
| 兼容性 | 现代浏览器（Chrome、Edge、Firefox、Safari 近两版）；仅使用标准 HTML/CSS/ES5+ 能力 |
| 性能 | 首屏无外部请求；交互为 DOM 级，无明显卡顿 |
| 可维护性 | 设计令牌集中于 `:root` CSS 变量；模块类名与规格一致 |
| 可访问性（建议） | 按钮/可点击区域具备可辨识 hover；弹窗打开时焦点在弹窗内（实现可选增强） |
| 安全 | 无后端、无用户数据上传；内容仅存于页面内存（刷新丢失，符合静态页预期） |
| 国际化 | 本期仅简体中文 UI 文案 |

### 设计令牌（:root）

| 变量 | 值 | 用途 |
|------|-----|------|
| --bg | #f4f5f7 | 页面底色 |
| --surface | #ffffff | 卡片/面板 |
| --border | #e2e5eb | 边框 |
| --text | #1a1d26 | 主文字 |
| --text-muted | #6b7280 | 次要文字 |
| --accent | #3b6fd9 | 主题蓝 |
| --accent-soft | #e8effc | 选中/标签浅蓝 |
| --radius | 10px | 圆角 |
| --shadow | 0 1px 3px rgba(0,0,0,.06), 0 4px 12px rgba(0,0,0,.04) | 卡片阴影 |

字体：界面 14px 无衬线栈；写作区 16px 衬线栈，`line-height:1.75`。

## 5. 界面与信息结构要点

### 5.1 大纲（左栏 220px）
- 标题「大纲」；列表可滚动。
- 一级「章」、二级 `.level-2`（缩进 28px、13px、灰色）。
- 选中：浅蓝底 + 左 3px 蓝条 + 蓝字。

### 5.2 顶部三栏卡片（等宽）
- 统一：白底、1px 边框、圆角、阴影；标题条 `#fafbfc`；body 可滚动。
- **脑图**：`.mindmap-thumb` 虚线 2px、渐变灰底、`cursor:pointer`；右下角 `::after`「点击放大、编辑」；内嵌示意 SVG。
- **关键词**：`.keyword-tags` 胶囊标签；输入 placeholder「添加关键词…」+ 蓝色「添加」。
- **剪贴板**：`.clipboard-list`，项含正文 + 灰色时间；`data-text` 存纯文本；初始 2 条示例。

### 5.3 提纲（200px）
- 标题「提纲」；`.synopsis-item` + `.num` 序号徽标。
- 选中：浅蓝底 + 蓝边框；徽标蓝底白字。

### 5.4 写作区
- 标题「写作区」+ 右侧 muted「在此正文创作」。
- 工具条：左「当前章节：…」，右 `margin-left:auto`「N 字」。
- `#writingArea` 填满剩余高度，`resize:none`。

### 5.5 脑图弹窗
- `.modal-overlay` 默认隐藏，`.open` 为 `display:flex` 居中。
- `.modal` 宽 `min(900px,100%)`，最高 90vh；头/体/底三区；说明可接入 markmap/jsMind。

### 5.6 响应式（max-width: 900px）
- 顶部 Grid → 单列；取消工具区固定高约束。
- 工作区 `flex-direction:column`；提纲 `width:100%`，`max-height:160px`。

## 6. 边界与异常（空态、错误、权限）

| 情况 | 预期行为 |
|------|----------|
| 关键词输入为空或仅空白 | 不创建标签，输入框可清空或保持 |
| 剪贴板 `data-text` 为空 | 不插入或插入空（实现应避免无意义换行） |
| 写作区为空时插入剪贴板 | 直接插入文本，不前置 `\n\n` |
| 写作区有内容且末尾非换行 | 先插入 `\n\n` 再插入剪贴板文本 |
| 脑图弹窗重复打开 | 保持单例遮罩，不叠层 |
| 点击遮罩空白 | 关闭弹窗（与取消一致） |
| 窄屏高度不足 | 各滚动区独立滚动，根容器 `overflow:hidden` 不撑破视口 |
| 权限 | 纯前端静态页，无登录与权限模型 |
| 数据持久化 | 刷新页面恢复初始示例数据（本期 out of scope） |

## 7. 验收标准（可测试条目）

1. 用浏览器直接打开 `写作工作台.html`：控制台**无报错**，网络面板**无外部请求**。
2. 宽屏下可见六大区域：大纲、脑图、关键词、剪贴板、提纲、写作区；布局与规格示意图一致（左 220px + 右主区上下分栏）。
3. 视口宽度 ≤900px 时：顶部三栏单列堆叠；工作区纵向；提纲全宽且 `max-height` 约 160px。
4. **脑图**：点击缩略打开弹窗；×、取消、遮罩关闭；「保存并缩小」将编辑区内容写回缩略预览并关闭。
5. **大纲 / 提纲**：各自列表点击为单选高亮，互不影响另一列表。
6. **关键词**：「添加」与输入框 Enter 均可追加非空标签并清空输入。
7. **剪贴板**：点击任一条目，写作区末尾按规则插入 `data-text`，字数更新，写作区获得焦点。
8. **写作区**：输入时字数 = 去掉所有空白字符后的字符数，实时显示在工具条右侧。
9. 页面加载后缩略与弹窗内均存在示意 SVG 脑图（中心「主题」+ 三分支）。
10. 下列 DOM ID 存在且可被脚本引用：`outlineTree`、`mindmapThumb`、`mindmapPreview`、`keywordTags`、`keywordInput`、`addKeyword`、`clipboardList`、`synopsisList`、`writingArea`、`wordCount`、`mindmapModal`、`mindmapEditor`、`modalClose`、`modalCancel`、`modalSave`。

## 8. 待定项与风险

### 待定项
| 项 | 说明 |
|----|------|
| 脑图真实编辑能力 | 本期为 SVG 占位；弹窗文案提示可接入 markmap / jsMind |
| 大纲/提纲/写作区联动 | 规格未强制切换章节时清空正文；是否按章分片存储待产品确认 |
| 数据本地持久化 | localStorage 自动保存可作为二期 |
| 导出 | Word/Markdown 导出未纳入本期 |

### 风险
| 风险 | 影响 | 缓解 |
|------|------|------|
| 单文件体积过大 | 维护成本上升 | 保持结构分区注释，令牌与组件类名稳定 |
| 移动端软键盘遮挡写作区 | 窄屏体验下降 | 响应式堆叠 + 写作区 flex 填满剩余高度 |
| 无自动保存 | 刷新丢稿 | PRD 明确 scope；二期加本地存储与离开页提示 |
| 浏览器差异（textarea、flex） | 布局轻微偏差 | 在目标浏览器清单中做冒烟验收 |
